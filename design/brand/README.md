# Baylior brand

Product: **Baylior** — Business Suite. Tagline: **One suite. Every detail.** (by Trovo Tech Solutions)

| File | Use |
|---|---|
| `baylior-logo-original.webp` | The approved logo (glow version) — marketing, social media, large screens |
| `baylior-mark.svg` | Flat "B" mark with the brand gradient — sign-in badge, website header |
| `baylior-icon.svg` | The mark on a dark rounded square — app icon, browser tab icon |
| `baylior-lockup-on-dark.svg` / `-on-light.svg` | Mark + wordmark side by side |
| `baylior-mark-mono-dark.svg` / `-mono-white.svg` | One colour — print, black-and-white documents, watermarks |

## Colours ("Baylior cyan", chosen 14 Oct 2026)

| Name | Hex | Use |
|---|---|---|
| Blue | `#2D6BFF` | Main colour: buttons, links, active menu |
| Cyan | `#14C8F0` | Highlights, figures, the second half of the gradient |
| Magenta | `#D63AF9` | Small accents only (e.g. "Every detail") |
| Night | `#0A0F1C` | Dark backgrounds |
| Panel | `#121A2B` | Cards on dark backgrounds |

Gradient: magenta → blue → cyan (logo), blue → cyan (buttons). Keep Trovo's red/purple out of Baylior screens.
